# 표면 규칙 (Surface Rules)

색·여백·모서리를 매번 다시 정하지 않기 위한 규칙. 2026-08-03 리디자인 세션에서 확정했고,
2026-09-03 상세페이지 v2 작업에서 **네 조항을 어겨 되돌린 뒤** 문서로 옮겼다.

---

## 1. 표면은 두 층뿐이다

| 층 | 색 | 쓰임 |
|---|---|---|
| 바닥 | `zinc-100` | 페이지 배경 |
| 표면 | `white` | 콘텐츠가 놓이는 유일한 면 |

`zinc-50`은 바닥으로 쓰지 않는다 — 흰 표면과 명도차가 2%뿐이라 테두리 없는 카드가 사라진다.

## 2. 회색 필은 인풋 전용

회색 면은 **눌린 것·입력받는 것**을 뜻한다. 그 위에 본문을 얹지 않는다.

- ✅ 인풋, pressed 상태, 작은 칩·알약(라벨 한두 단어)
- ❌ 리뷰 카드, 요약 문단, 안내 문장

> **2026-09-03 사고** — 리뷰 카드와 리뷰 작성 폼을 `bg-hair-2/60` 위에 얹었다.
> "회색 배경에 글씨를 써놓으니까 가독성이 떨어진다"는 지적을 받고 흰색으로 되돌렸다.
> 명암-높이 지각에서 어두운 면은 파인 것으로 읽힌다. 파인 곳에 글을 쓰지 않는다.

## 3. 테두리와 그림자를 쓰지 않는다

- 카드에 `border`·`shadow` 금지
- 호버에 그림자도, 배경 틴트도 주지 않는다 → **제목 색 전환 + 화살표(ArrowUpRight) 페이드인**
- 예외: **흰 배경 컨텍스트**(지도 패널·바텀시트)에서는 흰 카드가 안 보이므로 `border-zinc-200` 허용.
  컴포넌트는 `bordered` prop 으로 전환한다.

## 4. 상세페이지는 흰 시트 1장 + 내부 디바이더

섹션마다 카드를 씌우지 않는다. 시트 하나 안에서 `divide-y divide-zinc-100` 으로 나눈다.

```
페이지 (zinc-100)
└ 흰 시트 (rounded-[10px])
   ├ 히어로 ── divider
   ├ 후기 종합 ── divider
   └ …
```

## 5. 시트 안에 표면을 또 얹지 않는다

"카드 안에 카드"가 되는 순간 위계가 무너진다. 시트 안의 구획은 **선**으로 나눈다.

- ✅ `DividerGrid` / `DividerCell` (`src/components/wiki/SectionShell.tsx`) — 흰 바탕 + 1px 선
- ❌ 회색 면을 깔고 1px 틈으로 나누는 방식, 틴트 박스, 회색 웰

> **2026-09-03 사고** — 시안의 헤어라인 그리드(`gap:1px; background:hair-2`)를 그대로 옮겼는데,
> 그건 시안이 회색 바닥 위에 그려졌기 때문에 성립하는 조형이었다. 흰 시트 안에서는
> 회색 표면이 하나 더 생기는 셈이다. 색은 **라벨 한 조각**에만 쓴다
> (예: 무료 회차 안내 → 틴트 박스 대신 `혜택` 라벨만 초록).

## 6. 긴 텍스트는 가로로 나누지 않는다

AI 팁 3열 배치처럼 긴 글을 다열로 깔지 않는다. 세로 스택.

## 7. 액센트 색을 늘리지 않는다

`primary` 블루 하나. 상태색(good/warn/risk)은 라벨·아이콘에만 쓰고 면으로 깔지 않는다.

| 본문 폭 | 900px (패딩 포함) |

## 토큰

`src/styles.css` 의 `@theme` 에 시안 토큰을 **덧붙였다**(shadcn 토큰은 건드리지 않음).

`hair` `hair-2` `ink` `ink-2` `faint` `accent-tint` `accent-ink` `good` `good-tint`
`warn` `warn-tint` `risk` `risk-tint`

`hair-2`는 **선 색**이지 면 색이 아니다 (규칙 2·5 참조).
