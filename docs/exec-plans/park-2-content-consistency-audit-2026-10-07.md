# PARK-2 콘텐츠·후기 출처 일관성 점검 (2026-10-07)

## 범위와 확인 근거

고정 5곳의 공식 주차 안내와 `src/lib/verified-parking-guides.ts`의 요금·무료 조건을 대조했다. 공식 페이지는 2026-10-07에 다시 열어 확인했다. 상세페이지·FAQ·구조화 데이터는 이미 검증 가이드를 사용했지만, 지도 카드·패널·목록은 원본 `parking_lots` 요금과 이전 AI 요약을 사용했다. 운영 DB의 원본 값, 해당 5곳의 실제 후기 건수와 과거 지도 화면은 Cloudflare API의 7403 권한 오류로 확인하지 못했다. 따라서 실제 방문자에게 수치 충돌이 발생했다고 단정하지 않고, **서로 다른 데이터 원천이 같은 주차장에 표시될 수 있는 경로**를 제거했다.

## 표시 경로별 전후

| 표면 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 상세페이지·FAQ·JSON-LD | 5곳에 검증 가이드 요금 사용. AggregateRating은 시드 제외 실후기가 있을 때만 출력 | 유지. 공식 출처·확인일 및 비방문 안내도 유지 |
| 지도 상세 패널·모바일 카드 | 원본 DB 요금, 기존 AI 요약·요금/방문 팁 표시 | 5곳은 검증 가이드 요금·요약을 사용하고, 공식 출처와 2026-09-18 확인일 표시. 기존 AI 팁은 숨김 |
| 지도 목록 | 원본 DB의 무료/유료 표시 | 5곳은 검증 가이드 무료/유료 표시 |
| 홈·지역 카드 | 5곳의 무료/유료는 가이드 사용. 시드 포함 리뷰 수와 별 아이콘 옆 통합 난이도 점수 표시 | 실제 등록 후기 수만 표시. 통합 점수는 `쉬움`으로 표시해 사용자 별점과 구별 |
| 후기 카드·전체 후기 | 시드가 작성자·별점이 있는 사용자 리뷰처럼 표시될 수 있었고 외부 원문 링크가 보이지 않음 | 시드는 사용자 후기 목록·집계에서 제외. 외부 출처가 있는 후기는 원문 링크와 출처 표시. 전체 후기 화면의 방문 경험 단정 문구 제거 |
| 지역·사이트 리뷰 집계 | 시드 포함 | 시드 제외 |

`parking_lot_stats.final_score`는 후기·웹 글·구조 정보를 합친 쉬움 점수다. 평점 자체가 아니므로 별 아이콘과 `/5`를 제거했다. 점수 계산식과 순위는 변경하지 않았다. 지역 허브의 전체 후기 건수, 홈 카드의 후기 수, 상세페이지의 사용자 후기 수는 시드 제외 기준으로 맞췄다. `parking_lot_stats.review_count` 자체는 점수 계산 입력으로 남으며, 사용자 후기 수로 표시하지 않는다.

## 검증 및 남은 확인

- 요금 경계(특히 IFC의 30/31분) 기존 테스트, 지도 목록에서 원본 DB가 유료여도 위례를 공식 무료로 표시하는 회귀 테스트 등 관련 43개 테스트, 변경 파일 Biome 검사, 프로덕션 빌드 통과.
- 저장소 전체 `tsc --noEmit`는 기존 스크립트의 Bun 타입 누락과 서버 함수 타입 오류 등으로 실패한다. 이번 변경 파일의 새 오류는 확인되지 않았지만 전체 타입 검사 통과를 주장하지 않는다.
- 운영 DB 권한이 복구되면 5곳의 원본 요금·`is_seed`별 후기 건수와 공개 지도 화면을 재확인해 이 문서에 실측 전후 수치를 덧붙인다. 지금은 확인되지 않은 실측치를 적지 않는다.
- 이 변경은 정보의 출처와 표시 일관성을 개선한다. GSC 색인 전환이나 그 인과 효과를 보장하지 않는다.
