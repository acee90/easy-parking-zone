# PARK-3 URL·사이트맵·내부 링크 감사 (2026-10-01)

대상: [PARK-3](https://linear.app/outshinelee/issue/PARK-3/중복-url사이트맵내부-링크와-봇-응답을-표본-감사). 운영 응답과 운영 D1의 읽기 전용 집계를 대조했다. 이 문서의 HTTP 결과는 **수정 배포 전** 기준값이다. [대표 5곳 GSC 추적 기록](verified-parking-indexing-2026-09-18.md)은 별도로 유지한다.

## 표본과 결과

| URL 유형 | 운영 표본 | HTTP·색인·canonical | 사이트맵·내부 링크 | 조치 |
| --- | --- | --- | --- | --- |
| 홈 `/` | 1 | 200, 자기 canonical | 대표 5곳과 지역 허브 17곳으로 가는 HTML `<a href>` 확인 | 정상 |
| `/wiki` | 1 | 200, `index`, 자기 canonical | 대표 5곳과 지역 허브 링크 확인 | 정상 |
| 지역 허브 | 경기·서울 | 각각 200, `index`, 자기 canonical | 경기에서 관련 대표 상세 링크, 서울에서 IFC몰 링크 확인. 정적 사이트맵에도 포함 | `lastmod` 수정 |
| 대표 상세 | 아래 5곳 | 모두 200, `index`, 자기 canonical | 모두 `sitemap-3.xml`에 있고 `lastmod=2026-09-18`; 홈에서 직접 연결 | `lastmod` 수정 |
| 임의 이름 별칭 | `/wiki/alias-<ID>` 5곳 | 모두 200, `index`, canonical만 정식 URL 지시 | 사이트맵에는 없지만 ID만 맞으면 임의의 이름으로 같은 본문을 제공 | 정식 slug로 301 |
| 쿼리 변형 | 정식 URL + `?utm_source=park3-audit` 5곳 | 모두 200, 쿼리 없는 정식 URL을 canonical로 지정 | 추적 파라미터가 링크에 포함된 표본은 발견하지 못함 | 유지 |
| 호스트·프로토콜 | `www`·HTTP 홈 | 둘 다 HTTPS 비-www 홈으로 301 | `robots.txt`는 200이고 사이트맵 인덱스를 선언 | 정상 |

대표 상세 ID: 스타필드시티 위례 `KA-1935812519`, 스타필드 하남 `KA-732776068`, 스타필드 수원 `KA-644595051`, 현대백화점 판교점 `KA-27593534`, IFC몰 `KA-2056009871`. 예를 들어 [위례 정식 URL](https://easy-parking.xyz/wiki/%EC%8A%A4%ED%83%80%ED%95%84%EB%93%9C%EC%8B%9C%ED%8B%B0-%EC%9C%84%EB%A1%80-%EC%A3%BC%EC%B0%A8%EC%9E%A5-KA-1935812519)은 200인데 [같은 ID의 임의 별칭](https://easy-parking.xyz/wiki/alias-KA-1935812519)도 수정 전에는 200이다. 별칭은 이름 부분에 제약이 없어 가능한 URL 수를 유한하게 셀 수 없다. 실제 크롤링된 별칭의 수는 확인되지 않았다.

정적 사이트맵의 `/wiki/all`은 2026-08-03으로 표시됐지만 2026-09-09에 색인 대상 목록으로 변경됐다. 지역 허브도 2026-08-03으로 표시됐지만 2026-09-14에 집계·캐시가 바뀌고 2026-09-30에 공통 랭킹 카드의 요금 표시가 바뀌었다. `/wiki`는 2026-09-30에 대표 5곳 연결이 추가됐는데 `lastmod`가 2026-09-18이었다. 대표 상세 5곳의 공식 안내도 2026-09-30에 게시됐지만 사이트맵은 검증일인 2026-09-18을 표시했다. `/wiki/all`은 2026-09-09, 지역 허브·`/wiki`·대표 5곳은 2026-09-30으로 수정한다. 검증일과 페이지 수정일을 구분하고 오늘 날짜를 일괄 부여하지 않는다.

## 사이트맵 포함 조건의 범위

2026-10-01 운영 D1을 현재 사이트맵 SQL과 동일한 조건으로 읽기 전용 집계했다. `parking_lots`는 53,868곳, `sitemap-N.xml` 대상은 20,677곳이다. 조건의 `p.is_free IS NOT NULL`은 `is_free INTEGER NOT NULL DEFAULT 0`이므로 항상 참이다. 이 신호 하나로 3개 기준을 채우는 대상은 13,505곳이다. 이를 단순 제거하면 대상은 7,172곳으로 줄어든다.

다만 이 숫자는 **실제 `noindex` 페이지 수가 아니다**. 해당 13,505곳에서 ID 순서로 뽑은 5곳(구버스터미널일원 `000-1-000001`, 로데오거리 `000-1-000002`, 롯데백화점일원 `000-1-000003`, 중동먹거리 `000-1-000004`, 투나백화점일원 `000-1-000006`)은 모두 운영에서 200, `index`, 자기 canonical이었다. 상세의 색인 판정은 운영시간·요금·평점 등 추가 신호를 사용하므로, 사이트맵 조건의 결함만으로 13,505곳을 일괄 제외하면 유효한 URL도 사라진다. `is_free` 신호의 수정은 전체 사이트맵과 실제 메타 로봇 판정의 교집합을 측정하고 표본을 검수한 뒤 별도 작업으로 결정한다. 이번 변경에서 대량 `noindex`/삭제는 하지 않는다.

## GSC와 배포 후 확인

2026-09-30 GSC 기록에서 대표 5곳은 모두 Google이 2026-09-18에 크롤링했고, 가져오기·색인 허용 및 자기 canonical이 확인됐지만 0/5 색인 상태였다. GSC의 ‘참조 사이트맵 없음’은 실제 `sitemap-3.xml` 부재의 증거로 해석하지 않는다. 색인 요청을 반복 제출하지 않는다. 검증된 Googlebot 서버 로그는 확보하지 못했으므로 curl/User-Agent 응답으로 Googlebot의 성공·차단을 주장하지 않는다.

배포 후에는 정식 5곳이 200·자기 canonical을 유지하고 별칭 5곳이 동일 ID의 정식 URL로 301이 되는지, 정적 사이트맵과 대표 5곳의 `lastmod`가 수정됐는지 확인한다. 다음 GSC 확인은 기존 추적 일정(10월 2일)에서 크롤링 시각·상태 변화를 기록한다. Google 문서상 [사이트맵은 원하는 canonical URL을 제출하는 수단](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)이며, [크롤링 가능한 내부 링크](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)가 발견을 돕지만 색인을 보장하지 않는다.
