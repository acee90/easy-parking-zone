### 지킨 원칙 (검증됨)

- **분위기는 별점이 아니다** — 화면에 `N/5` 숫자도 별 아이콘도 쓰지 않는다.
  "무난하다는 평" 같은 라벨 + 좋았다/보통/아쉬웠다 분포 막대로만 그린다.
  `AggregateRating` 으로도 내보내지 않는다.
- **3건 미만이면 분포 막대를 안 그린다** — 1~2건 평균은 평점이 아니다.
- **원문은 한 조각도 안 그린다** — 2-4 는 제목·도메인·날짜·링크만.
- **정보 모음 사이트는 집계에서 뺀다** — 안 그러면 경쟁사 페이지 점수가 평균에 섞인다.

**라이브 검증 (차이나타운 `161-2-000155`)**: 웹 후기 18건 · 좋았다 7 / 보통 9 / 아쉬웠다 2 ·
태그 혼잡 4 · 넓음 1 · 주의 필요 1 · 진입 어려움 1 · 협소 1.
SQL 직접 집계와 값이 정확히 일치. 태그가 원형(혼잡/만차/복잡)에서 하나로 모인 것도 확인.

### 2-5 / 2-6 가 남은 이유

2-5(한 줄 결론 + 규모·혼잡·진입·요금 라벨 목록)는 **lot 단위 구조화 요약**이 있어야 그린다.
지금 `parking_lot_stats.ai_summary` 는 산문 한 덩어리이고 그마저 **22개 lot(0.07%)** 뿐이다.

"3개의 대형주차장", "정보없이 네비에 찍힌 선상주차장" 같은 문장 조각이 그쪽에 몰려 있었다.

**라이브 검증 (차이나타운)**: "인천내항제8부두 주차장 [무료] 후기 4건에서 함께 언급",
"동화마을공영주차장 후기 3건". 무료 배지는 추출 힌트가 아니라 **매칭된 주차장의 실제 `is_free`** 다.

**경쟁사에 없는 기능이다.** 차이나타운 표본에서 "인천내항 8부두 주차장(무료)" 5건,
"송월동 동화마을 공영주차장" 3건이 관측됐다. 사람들이 그 블로그를 읽는 진짜 이유이고,
부수적으로 내부 링크가 는다.

**정밀도 우선** — 오매칭 하나가 사람을 엉뚱한 주차장으로 보낸다.
추출 모듈은 "이 주차장" "근처 주차장" 같은 지시어를 버리고, 고유명이 없는 후보는 만들지 않는다.
이름을 짧게 잘라 매칭에 실패하는 쪽은 감수하되, 없는 이름을 지어내지는 않는다.

**3-1b 가 남은 이유** — 저장할 테이블이 없다. 그리고 원천 선택이 걸려 있다:
`web_sources_raw_body.full_text` 는 처리 후 purge 되므로(0단계) 배치를 파이프라인 안에 넣거나,
`web_sources.content`(최대 1,000자) + `ai_summary`(평균 326자)로 대신해야 한다.
후자가 지금 당장 가능하고, 차이나타운 표본에서는 그 짧은 텍스트에도 8부두가 등장한다.

| 주장 | 왜 틀렸나 |

### 확인된 개선 (검수 중 반영)

- `normalizeLotName` 이 `제8부두` ↔ `8부두` 를 다르게 봐서 **기능의 핵심 사례가 매칭되지 않았다.**
  서수 `제` 만 떼도록 고쳤다. 안전성은 전체 31,994곳으로 실측 — 새로 겹치는 이름 25건뿐이고
  그마저 대부분 같은 주차장의 다른 표기다. 적용 후 "인천내항 제8부두 주차장" 4건이 매칭된다.
- 배치 스크립트가 **같은 주차장의 여러 표기를 합치지 않아** 카드에 같은 곳이 두 줄로 나올 수 있었다.
  매칭된 lot 기준으로 합산하도록 고쳤다.

## 검증 지표

**글자 수와 "자체 콘텐츠 비중"은 지표로 쓰지 않는다.** 계산해 만든 값을 검색엔진이 고유 콘텐츠로 인정한다고 볼 근거가 없고, 분량을 목표로 잡으면 경쟁사처럼 `0min 0` 을 발행하는 쪽으로 간다.

| 단계 | 지표 | 지금 잴 수 있나 |
|---|---|---|
| 0 | 정보 모음 사이트 노출 수 → 0 | ✅ SQL |
| 0 | 메뉴 글자 포함 요약 수 → 0 | ✅ SQL |
| 1 | 요금 계산 가능 lot 에서만 계산기가 뜨는가 | ✅ 라이브 |
| 1 | 잘못된 요금·주소 안내 건수 → 0 | ✅ 표본 감사 |
| 2 | 원문 복사 문장 → 0 | ✅ 라이브 크롤 |
| 2 | AI 요약 **정확도** (커버리지 아님) | ⚠️ 표본 QA 필요 |

| 전 구간 | GSC 색인율·노출·클릭 | ❌ 사람이 GSC 에서 확인 |
