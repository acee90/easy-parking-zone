## 2. 새로 드러난 것 — 사이트맵이 Google에게 거짓말을 하고 있다

`sitemap-handler.ts:76-88`(과 `:341-353`, 동일 블록 2벌)의 포함 조건:

```sql
WHERE EXISTS (web_sources ... AND filter_passed_v2 IS NOT 0)
   OR s.ai_summary IS NOT NULL
   OR p.curation_reason IS NOT NULL
   OR ( total_spaces>0 + phone非빈 + is_free IS NOT NULL + curation_tag非NULL ) >= 3
```

**4번째 가지가 문을 열어놨다.** `is_free`는 `integer(...).notNull().default(false)`(`schema.ts:94`)라 `IS NOT NULL`이 **항상 1**이다. 따라서 저 조건은 실질적으로 **나머지 3개 중 2개**만 있으면 통과다 — 면수와 전화번호만 있으면 들어온다. 콘텐츠 신호가 아니다.

파일 헤더 주석(`:8`, `:16`)은 *"sitemap-N.xml : web_sources 있는 주차장 / thin 주차장은 완전 제외(#126)"* 라고 적혀 있지만 **코드는 그렇게 동작하지 않는다.**

### 측정된 결과 (sitemap 색인대상 115건 표본)

| 구분 | 비율 | 20,286 대비 추정 |
|---|---:|---:|
| 웹 출처 보유 | 32% (±9%p) | ~6,500 |
| 큐레이션 사유 보유 | 4% (±4%p) | ~800 |
| lot AI 요약 보유 | 3% (±3%p) | ~600 |
| 리뷰 보유 | 3% (±3%p) | ~600 |
| **넷 다 없음 = 순수 템플릿 껍데기** | **66% (±9%p)** | **~13,400** |

sitemap 밖(noindex) 표본 5건은 100% 순수 thin — 차단은 정상 동작한다. 문제는 **차단선이 너무 아래에 그어져 있다**는 것이다.

### 왜 이게 최우선인가

Google에게 "색인할 가치가 있다"고 신고한 20,286개 중 **약 13,400개가 공공데이터 필드 치환 + 자동 FAQ + 주변 주차장 표뿐이다.** 이건 경쟁사 mustarddata가 32,184개로 하고 있는 것과 **정확히 같은 종류의 페이지**다. 그 축에서는 이길 수 없다 — 저쪽은 정적 파일이라 TTFB가 10배 빠르고 페이지 수도 1.5배다.

우리가 이길 수 있는 축(난이도·리뷰·AI 요약)은 **색인 대상의 7%**(AI요약 3% + 리뷰 3% + 큐레이션 4%의 합집합, 중복 제외 시 ~7%)뿐이다.

**보강의 방향은 "넓히기"가 아니라 "모으기"다.**

## 3. Gate 0 — 이것부터 (사람, 30분)

9/2 문서 §2-3의 판별 절차는 GSC를 못 보던 때 쓰였다. 지금은 볼 수 있다.

**GSC > 색인 생성 > 페이지 > "색인이 생성되지 않은 이유"의 사유별 건수**를 기록할 것.

| 지배적 사유 | 의미 | 1순위 |
|---|---|---|
| `noindex 태그에 의해 제외됨` | 우리가 의도한 차단 (54,072 중 33,786) | **대응 불필요.** 16,834의 정체가 이거라면 지금 상태는 정상이다 |
| `발견됨 – 현재 색인이 생성되지 않음` | 크롤 예산 부족 | **M1(게이트 축소) + M3(TTFB)** |
| `크롤링됨 – 현재 색인이 생성되지 않음` | 보고 나서 가치 없다고 판정 | **M1 + M2(AI 요약 확대)** |
| `중복 페이지…` | 출처별 중복 lot | 출처 간 lot 병합 (비용 높음, 후순위) |

함께 필요한 숫자 하나 더: **GA4의 `/wiki` 주간 세션 수.** 9/2 문서 §5-3 주석 3이 지적한 대로, 이 값 없이는 리뷰 목표치를 세울 수 없다("87 → 3개월 500 lot"은 근거 없는 수치라고 그 문서가 스스로 밝혔다).

### 하지 말 것

- **넓히기**: 남은 33,786개 thin lot을 색인 대상으로 올리는 것. 경쟁사 축에서 정면 대결하는 셈이고 이길 수 없다.
- **GSC 사유 확인 전에 M2에 돈 쓰기**: `발견됨-미색인`이 지배적이면 AI 요약을 아무리 만들어도 Google이 그 페이지를 안 가져간다.
- **트래픽 실측 없이 리뷰 목표 세우기**: 9/2 문서가 이미 거부한 것.

## 5. 표본 한계

전부 115건(sitemap) / 5건(noindex) 표본 기반이며 ±는 95% 신뢰구간이다. remote D1 전수 조회가 아니다 — `.dev.vars`에 `D1_PROXY_TOKEN`이 없어 이 세션에서는 D1 직접 조회가 불가능했다. **M1을 실행하기 전에 새 술어의 통과 건수를 remote에서 전수로 확인할 것.** 추정 ~6,900이 실제로 몇 건인지에 따라 판단이 달라질 수 있다.
